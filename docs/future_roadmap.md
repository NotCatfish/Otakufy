# Future Features

1. **Versus Mode**: A competitive 2-player battle mode where users race against each other on the same set of decks to compete for leaderboard positions.
2. **Cloud Save**: True cloud-syncing for mid-quiz save states, allowing users to pause a session on one device and seamlessly resume it on another without losing their queue or points.
3. **Listening Practice**: New question formats featuring audio playback to test and improve Japanese listening comprehension.
4. **Production Security Hardening**: Set up a centralized global rate limiter (e.g., Upstash Redis) to handle serverless deployments securely, and configure a Web Application Firewall (like Cloudflare) to provide robust DDoS protection prior to a public launch.
